Learning objectives

What you should be able to do

Use these objectives to check your understanding after each class. For example, 9B.1 means Week 9, Class B, objective 1.

Class A

Testing a claim

Back to class ↑
  1. 9A.1State null and alternative hypotheses using population parameters.
  2. 9A.2Choose a one-tailed or two-tailed test from the research question.
  3. 9A.3Explain significance levels and distinguish Type I from Type II errors.

Class B

One-sample tests

Back to class ↑
  1. 9B.1Choose an appropriate one-sample z-test or t-test and state its assumptions.
  2. 9B.2Calculate a test statistic and obtain or interpret its p-value.
  3. 9B.3Use the significance level to decide whether to reject the null hypothesis.

Class C

Hypothesis testing workshop

Back to class ↑
  1. 9C.1Organise a complete hypothesis test from a contextual question.
  2. 9C.2Apply a suitable test and justify the decision using sample evidence.
  3. 9C.3Write a conclusion in context and distinguish failure to reject from proof of the null hypothesis.
