About Course

Statistics helps us turn data into evidence. In this 12-week foundation course, you will learn how to collect reliable data, summarise a dataset, present results clearly and use probability to understand uncertainty.

We begin with the calculations needed for statistics, then move through sampling, descriptive measures, charts and Excel. Later topics introduce probability distributions, confidence intervals, hypothesis tests and regression, using examples from business and science.

Each concept follows a clear sequence: a worked demonstration, guided practice and an independent task. You will practise calculations, interpret what the answers mean and explain your conclusions in plain English.

What Will You Learn?

  • Choose sampling methods and recognise bias.
  • Describe the centre, spread and shape of data.
  • Build and interpret statistical charts in Excel.
  • Calculate probabilities and use distribution models.
  • Estimate population values and test claims.
  • Interpret correlation and regression results.

Course Content

12 weeks · 40 classes

Every class lasts 90 minutes. Class D tutorials take place in Weeks 2, 5, 8 and 11.

Week 01 · Mathematical foundations3 classes
A

Class A · Numbers and counting

Build the mathematical toolkit for statistics: use set notation and Venn diagrams, select counting methods, classify numbers and calculate accurately using PEMDAS.

90 min
B

Class B · Calculations in context

Solve linear and simple quadratic equations, convert units, and use percentages and ratios to make and justify numerical decisions.

90 min
C

Class C · Applied problem solving

Apply the Week 1 toolkit to a connected product case, from customer evidence and product choices to packaging, material quantities and sales revenue.

90 min
Week 02 · Sampling and collecting data4 classes
A

Class A · Populations, samples and variables

Identify the group being studied, distinguish sample statistics from population parameters, classify data and carry out simple random or systematic selection.

90 min
B

Class B · Organising a dataset

Develop stratified and cluster sampling plans, distinguish chance variation from bias, and evaluate the reliability and practical cost of survey evidence.

90 min
C

Class C · Survey workshop

Investigate a canteen survey, check whether its claims follow from the data, repair its sampling and measurement methods, and write a defensible report.

90 min
D

Class D · Tutorial: review, repair and prepare

Review numerical skills and sampling, revisit difficult steps and prepare for assessment.

90 min
Week 03 · Descriptive statistics3 classes
A

Class A · Centre, spread and distribution shape

Mean, median and mode; range, quartiles using n + 1, IQR and five-number summaries; interpret skewness and the effect of extreme values.

90 min
B

Class B · Understanding variation

Deviations, population and sample variance, standard deviation, coefficient of variation and kurtosis; calculate and interpret absolute and relative spread.

90 min
C

Class C · Paper supplier workshop

Compare two suppliers using delivery-time averages, IQR, sample SD and CV; justify decisions for routine orders and changing deadlines. Formative Assessment 1 follows the workshop.

90 min
Week 04 · Data presentation and Excel3 classes
A

Class A · Organising and summarising data

Frequency and percentage tables, bar and pie charts, class intervals and midpoints, estimated grouped means, and stem-and-leaf plots.

90 min
B

Class B · Distributions and relationships

Histograms, frequency polygons, cumulative tables and ogives; estimate medians, plot relationships, use a line of best fit and compare boxplots.

90 min
C

Class C · Campus café Excel practical

Use café data to build frequency tables, a bar chart, histogram and scatterplot in Excel; interpret the evidence and recommend how to reduce food waste.

90 min
Week 05 · Basic probability4 classes
A

Class A · Sets, events and Venn diagrams

Sample spaces, set notation, complements, intersections and unions; probability from diagrams.

90 min
B

Class B · Probability rules

Addition rules, mutually exclusive events and independence through worked and guided examples.

90 min
C

Class C · Applied probability practice

Use Venn diagrams and probability trees to solve multi-step problems and explain event relationships.

90 min
D

Class D · Tutorial: review, repair and prepare

C

90 min

Class B · Normal distribution and z-scores

90 min
C

A

Class A · Sampling distributions

B

Class B · Confidence intervals

Class C · Estimation workshop

90 min
