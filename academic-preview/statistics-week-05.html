Learning objectives

What you should be able to do

Use these objectives to check your understanding after each class. For example, 5B.1 means Week 5, Class B, objective 1.

Class A

Sets, events and Venn diagrams

Back to class ↑
  1. 5A.1Describe a sample space and identify events within it.
  2. 5A.2Use union, intersection and complement notation to describe event relationships.
  3. 5A.3Calculate probabilities from labelled Venn diagrams.

Class B

Probability rules

Back to class ↑
  1. 5B.1Use the addition rule to calculate the probability of a union.
  2. 5B.2Identify mutually exclusive events and explain the effect on the addition rule.
  3. 5B.3Distinguish independence from mutual exclusivity in contextual examples.

Class C

Applied probability practice

Back to class ↑
  1. 5C.1Represent a probability problem using a Venn diagram or tree.
  2. 5C.2Combine probabilities along and across appropriate branches.
  3. 5C.3Explain the event relationships used in a multi-step solution.
