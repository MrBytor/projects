Statistics with Project Skills

Numbers and counting

Week 01 · Class A90 minutesFoundation · Business & Science

Mathematical foundations

What this class covers

  • Course introduction, evidence and sampling through the Mystery Bag demonstration.
  • Set membership, cardinality, empty and universal sets; union, intersection and complement; two-set Venn diagrams.
  • Basic counting principle, factorials, permutations and combinations; explain whether roles or order matter.
  • Natural, whole, integer, rational, irrational and real numbers.
  • Order of operations with powers, roots and nested brackets; diagnose equal-priority left-to-right errors.

Learning objectives

  • Use basic set notation and calculate set operations.
  • Select and apply a suitable counting method.
  • Classify common real numbers after simplifying them.
  • Evaluate expressions using PEMDAS/BODMAS and explain the order of operations.
