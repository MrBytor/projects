Learning objectives

What you should be able to do

Use these objectives to check your understanding after each class. For example, 7B.1 means Week 7, Class B, objective 1.

Class A

Continuous variables and probability area

Back to class ↑
  1. 7A.1Identify measurement scales and distinguish continuous measurements from discrete counts.
  2. 7A.2Calculate probabilities as areas under a rectangular density model.
  3. 7A.3Interpret F(x) as cumulative probability and use it to find interval probabilities.

Class B

Normal distribution and z-scores

Back to class ↑
  1. 7B.1Describe the shape and key properties of a normal distribution.
  2. 7B.2Calculate and interpret a z-score.
  3. 7B.3Find lower-tail, upper-tail and interval probabilities using the standard normal distribution.

Class C

Applying the normal model

Back to class ↑
  1. 7C.1Translate contextual questions into normal probability calculations.
  2. 7C.2Find a percentile or threshold by converting a z-score to the original measurement scale.
  3. 7C.3Interpret results with appropriate units and check whether an answer is reasonable.
