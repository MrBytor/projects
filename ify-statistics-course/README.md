# IFY Statistics with Project Skills

A simple, responsive course overview with expandable topics for all 24 teaching weeks:

- Semester 1: Statistics (Weeks 1–12).
- Semester 2: Project Skills (Weeks 13–24).

## Open the website

Open `index.html` in a browser. All styles and the favicon are included in that file, so there are no dependencies or build steps.

The deployed version is at https://ify-statistics-course.jacob1986.chatgpt.site and currently requires the owner's access.

## Edit the course content

Edit the weekly `<details>` sections in `index.html`. The embedded `<style>` block controls the appearance and mobile layout.

The outline is based on the supplied IFY Semester 1 and Semester 2 teaching materials. Weekly content may be adapted in class.

This folder contains a copy of the deployed page. Changes committed here do not automatically update the Sites deployment.
